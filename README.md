# Sistema-Inteligente-de-Escrita-Assistida-de-Relat-rios-SIEAR-
O Sistema Inteligente de Escrita Assistida de Relatórios (SIEAR) é uma aplicação desktop desenvolvida em Electron que utiliza Inteligência Artificial executada localmente para auxiliar usuários na criação de relatórios profissionais. Seu principal objetivo é transformar descrições em linguagem natural em relatórios estruturados.
